## Название проекта: 

Расчёт метрик сервиса доставки еды.

## Описание проекта: 

Анализ основных метрик сервиса доставки еды (DAU, Conversion Rate, AOV, LTV, RR) при помощи SQL-запросов. 
Создание визуализации в DataLens. 

Для анализа были использованы SQL-запросы (PostgreSQL), Yandex DataLens.

## Общие выводы:

Анализ метрик показал необходимость стабилизации метрики DAU, с последующей оптимизацией конверсии и маркетинга.
